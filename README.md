# X-Road Metrics AI Dashboard

A web project combining an X-Road metrics dashboard concept with an AI chat interface. The repository documentation describes a dashboard using demo data and a Gemini-powered chat route.

## Main areas
- X-Road metrics dashboard
- Demo-data visualizations
- AI chat interface
- Server-side Gemini API integration
- Vercel deployment configuration

## Technology
JavaScript · Gemini API · Vercel

## Deployment
1. Import the repository into Vercel.
2. Add `GEMINI_API_KEY` under project environment variables.
3. Deploy and verify the dashboard and chat routes.

Follow the configuration files in the repository for the exact build and runtime settings.

## Operational considerations
Clearly label demo data and do not present it as live measurements from an X-Road ecosystem. Keep API keys server-side, apply rate limits to public chat endpoints and avoid exposing private operational metrics.

## Future improvements
Connect authenticated metrics sources, add role-based access, provide metric provenance and introduce tests for dashboard data transformations.
